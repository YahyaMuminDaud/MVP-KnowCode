Who's talking

The real issue

There's a growing disconnect between student and worker.

AI has made it easy to skip learning how to write code by hand. What it's leaving behind is a growing gap in real skill — and almost nobody's teaching how to close it.

Where I'm at

My attempt at fixing this is still a work in progress.

So I built KnowCode

A gym for reading code — flag the bug, name the cause, ship the fix.

function sumArray(nums) {
  for (let i = 0; i <= nums.length; i++) {
    total += nums[i];
  }
  return total;
}
What's the root cause of this bug?
Off-by-one: the loop condition should use < instead of <=
total should be initialized to 1 instead of 0
The function is missing a return statement

Why this, specifically

You don't need to write the loop by hand anymore. You still need to know it's broken.

KnowCode is deliberate practice for exactly the skill AI took off the table — not writing code, reading it.
